# RGB-Display-16-x-16

Tato práce se zabývá návrhem a realizací multifunkčního RGB LED displeje o rozměru 16 × 16 pixelů řízeného mikrokontrolerem ESP32. Cílem práce bylo vytvořit samostatné zobrazovací zařízení s více provozními režimy a vlastním způsobem ovládání. Displej je tvořen z adresovatelných LED diod typu WS2812B uspořádaných do čtvercové matice. Součástí řešení je displejové menu, které je ovládáno pomocí externího kabelového ovladače a umožňuje přepínání jednotlivých funkcí zařízení. Implementovány byly digitální hodiny synchronizované přes Wi-Fi s ukládáním času do modulu reálného času DS3231, zobrazení teploty a vlhkosti z čidla DHT11, sada dekorativních animací, hra Had s zobrazením skóre a VU metr využívající digitální mikrofon INMP441. Další funkcí je možnost vzdáleného kreslení na displej prostřednictvím webového rozhraní vytvořeného na platformě ESP32. Výsledkem je vizuálně atraktivní a interaktivní zařízení určené především k dekorativnímu zobrazení, které lze dále rozšiřovat o nové režimy a funkce.

This thesis describes the design and implementation of a multifunctional 16 x 16 RGB LED display controlled by an ESP32 microcontroller. The objective was to develop a standalone display device featuring multiple operating modes and a custom control system. The display consists of WS2812B addressable LEDs arranged in a square matrix. The solution includes a display menu operated via an external wired controller, allowing users to switch between various functions. Implemented features include digital clocks synchronized over Wi-Fi with time storage in a DS3231 real-time clock module, temperature and humidity display using a DHT11 sensor, a set of decorative animations, the game Snake with score tracking, and a VU meter utilizing an INMP441 digital microphone. Additionally, the device supports remote drawing via a web interface. The result is a visually attractive device designed for decorative purposes, with potential for further expansion of functions.
